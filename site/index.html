100% Local & LAN-First · Zero Telemetry · Local LLM or Gemini AI

Know where everything lives at home — in seconds.

Wherezy is a self-hosted household inventory tracker that runs from a single standalone binary or Python package. Organize rooms, shelves, and bins with custom schemas, print QR & barcode labels, track borrowed tools and expiring items, and speed up entry with voice or photos using Ollama, LM Studio, or Gemini.

What Wherezy Will Do For You

Built for real household clutter, shared storage rooms, toolshed lending, medicine expiration dates, and fast moving boxes.

AI

Voice, Photo & Prompt AI

  • Local LLM or Gemini: Switch between offline Ollama / LM Studio / llama.cpp or Gemini API key.
  • Auto-fill everything: Generate category schemas, fill item forms, sort Quick Capture Inbox, extract batch items, and scaffold room trees.
#

Custom Schemas & Starters

  • 7 field types: text, longtext, number (with units like mg, W), date, dropdown, multiselect, checkbox.
  • Drag-and-drop & templates: Reorder fields anytime and start fast with Medicines, Lights, Tools, and Documents.
L1

Nested Location Trees

  • Exact shelf paths: Model House › Garage › Steel Rack › Shelf 2 › Bin A.
  • Safe refactoring: Cycle prevention, batch multi-item moves, and guarded delete protection.
QR

QR Labels & 3-Mode Scan

  • Print labels: Item (I01) & location (L1) QR + Code 128 sheets (Avery 3x8, 4x10, thermal roll).
  • Works over plain HTTP Wi-Fi: Phone Photo Capture fallback joins live video & USB barcode scanners.
↔

Checkouts, Expiry & Moves

  • Taken-out log: Mark items borrowed with borrower name & timestamp so tools come back.
  • Expiry & moving boxes: Configurable expiry alerts, recurring reminders, and packed box manifests.
ZIP

Profiles, Privacy & Backups

  • Multi-user roles & PINs: Admin, Co-Admin, Member, Viewer, and Wallboard Display + audit logs.
  • Zero lock-in: 1-click full .zip backups, pre-restore snapshots, and Excel/CSV/JSON export.

Instructions & Setup Guide

Up and running in under a minute on Windows, Linux, or macOS — including optional AI setup.

1 Launch on Windows / Linux / macOS

Download the binary for your OS above and start Wherezy. Add --open to launch your browser automatically.

./wherezy --host 0.0.0.0 --port 8000 --open
2 Choose Custom Port or Data Folder

By default Wherezy creates a ./data folder next to the executable for SQLite, photos, and backups. Override it anytime:

./wherezy --port 8080 --data-dir ./wherezy-data
3 Sign In & Create Household Profiles

Open http://localhost:8000, pick the Admin profile, change the default PIN in Settings, and add Member or Viewer profiles for family members.

4 Seed Categories & Add Your First Items

Import starter templates (Medicines, Tools, Lights, Documents) or generate custom ones, then print QR labels!

1 Start Ollama or LM Studio

Run Ollama or LM Studio on the same machine or LAN. Pull a structured-JSON or vision model for photo item scanning:

ollama pull qwen2.5:7b ollama pull qwen2.5-vl:7b
2 Configure Settings › AI Assistant Provider

Switch provider toggle to Local LLM (Ollama / LM Studio / Custom) and click the Ollama (http://127.0.0.1:11434/v1) or LM Studio (http://127.0.0.1:1234/v1) preset chip.

3 Fetch Models & Optional Voice STT

Click Fetch Models to pick your loaded model with one click. Optionally specify a Whisper endpoint model (e.g. whisper-1) if you want microphone recordings transcribed when using a text/vision chat model.

4 Test Connection & Save

Hit Test Connection to verify round-trip JSON output and latency, then click Save AI Settings. Optional Bearer API keys are Fernet-encrypted at rest.

1 Option A: Paste Key in Settings (Encrypted)

Go to Settings › AI Assistant Provider, choose Cloud API Key (Gemini), paste your key, keep or override the model (gemini-3.8-flash), and click Test Connection + Save AI Settings.

2 Option B: Pass Server Environment Variable

Prefer headless config? Export GEMINI_API_KEY (and optionally WHEREZY_GEMINI_MODEL) before launching the binary or container:

GEMINI_API_KEY="AIza..." ./wherezy --open
1 Open Wherezy on Your Phone Over Wi-Fi

Find your computer’s LAN IP (192.168.x.x) and visit http://<LAN-IP>:8000 from any phone or tablet on the same Wi-Fi network.

2 Scan Codes Without HTTPS Setup

On plain HTTP LAN links, use Scan › Take Photo of Code to decode QR or Code 128 barcodes from camera snapshots — or scan labels directly with your phone’s native camera to open /#/i/<id>.

3 Back Up Everything in 1 Click

Go to Settings › Database & Storage and click Download Backup (.zip) to snapshot inventory.db, photos/, and files/ before upgrading or moving machines.

4 Keep Existing Data When Upgrading

Replace your old binary with the newer release while pointing to the same ./data folder — SQLite migrations upgrade schemas automatically on startup.
